# ถอดเสียงวิดีโอ (Video Transcriber)

แอปเดสก์ท็อปสำหรับถอดเสียงจากวิดีโอหรือไฟล์เสียงเป็นข้อความด้วย OpenAI API ใช้ได้ทั้ง Windows และ macOS แอปจะบอกค่าใช้จ่ายโดยประมาณให้ก่อนเริ่มทุกครั้ง

## ความสามารถ

- ถอดเสียงจาก **วิดีโอและไฟล์เสียง** เช่น mp4, mov, mkv, avi, webm, mp3, wav, m4a, aac, flac และ ogg ไฟล์ยาวเป็นชั่วโมงก็ได้ เพราะแอปจะตัดเป็นช่วงให้เอง
- **ประเมินค่าใช้จ่ายก่อนเริ่ม** เป็นทั้งดอลลาร์และบาท โดยปรับอัตราแลกเปลี่ยนเองได้
- **ให้ GPT ปรับคำให้อ่านง่าย**: แก้คำผิด ตัดคำซ้ำ ใส่วรรคตอน และแบ่งย่อหน้า โดยไม่ตัดเนื้อหา
- **ประวัติ**: ย้อนดูข้อความที่เคยถอด พร้อมยอดค่าใช้จ่ายรวม
- คัดลอกหรือบันทึกผลเป็นไฟล์ `.txt`
- มี ffmpeg ในตัว ไม่ต้องติดตั้งอะไรเพิ่ม

## ดาวน์โหลด

ไปที่หน้า **[Releases](../../releases/latest)** แล้วเลือกไฟล์ตามเครื่องของคุณ

| เครื่อง | ไฟล์ |
|---|---|
| Windows 10/11 | `VideoTranscriber-Windows-Setup.exe` |
| Mac ชิป Apple (M1/M2/M3/M4) | `VideoTranscriber-macOS-AppleSilicon.dmg` |

ถ้าไม่แน่ใจว่า Mac ใช้ชิปอะไร ให้กดเมนู  → About This Mac แล้วดูที่บรรทัด Chip หรือ Processor

## วิธีติดตั้ง

### Windows

1. ดับเบิลคลิก `VideoTranscriber-Windows-Setup.exe`
2. ถ้าขึ้นหน้าจอสีฟ้า "Windows protected your PC" ให้กด **More info** แล้วกด **Run anyway** ที่ขึ้นแบบนี้เพราะแอปยังไม่ได้ซื้อใบรับรองการเซ็นโค้ด
3. กด Next ไปจนจบ ไม่ต้องใช้สิทธิ์ admin
4. เปิดแอปจาก Start Menu หรือไอคอนบน Desktop

### macOS

1. ดับเบิลคลิกไฟล์ `.dmg` แล้วลาก **VideoTranscriber** ไปวางในโฟลเดอร์ **Applications**
2. ครั้งแรกให้ **คลิกขวา** ที่แอปในโฟลเดอร์ Applications แล้วเลือก **Open** จากนั้นกด Open อีกครั้ง
   ถ้ายังเปิดไม่ได้ ให้ไปที่ System Settings → Privacy & Security แล้วกด **Open Anyway**
3. ครั้งต่อไปเปิดได้ตามปกติ

## วิธีใช้

1. สมัครและสร้าง API Key ที่ [platform.openai.com/api-keys](https://platform.openai.com/api-keys) ต้องเติมเครดิตในบัญชีก่อน
2. เปิดแอป แล้วกดปุ่ม **วาง** ข้างช่อง API Key หรือกด Ctrl+V
3. กด **+ เพิ่มไฟล์** แล้วเลือกวิดีโอหรือไฟล์เสียง แอปจะแสดงค่าใช้จ่ายโดยประมาณทันที
4. เลือกโมเดลและภาษา (`th` = ไทย, `en` = อังกฤษ หรือเว้นว่างให้แอปตรวจภาษาเอง)
5. กด **เริ่มถอดเสียง** แล้วยืนยันค่าใช้จ่าย
6. ถ้าต้องการให้อ่านง่ายขึ้น กด **✨ ให้ GPT ปรับคำให้อ่านง่าย**
7. กด **บันทึก .txt** หรือ **คัดลอก** ไปใช้งาน

## ค่าใช้จ่าย

แอปไม่มีค่าใช้จ่าย คุณจ่ายแค่ค่าใช้ OpenAI API ผ่านบัญชีของคุณเอง ราคาที่แอปใช้คำนวณ:

| โมเดล | ราคา | ตัวอย่าง วิดีโอ 1 ชั่วโมง |
|---|---|---|
| gpt-4o-mini-transcribe (แนะนำ) | $0.003 / นาที | ≈ $0.18 (≈ 6 บาท) |
| gpt-4o-transcribe (แม่นกว่า) | $0.006 / นาที | ≈ $0.36 (≈ 12 บาท) |
| whisper-1 | $0.006 / นาที | ≈ $0.36 (≈ 12 บาท) |
| ปรับคำด้วย gpt-4o-mini | $0.15 / $0.60 ต่อ 1 ล้าน token (เข้า/ออก) | ข้อความ 1 ชั่วโมง ≈ 1 บาท |

ตัวเลขเหล่านี้เป็นค่าประมาณ ยอดจริงดูได้ที่ [OpenAI Usage](https://platform.openai.com/usage) และ OpenAI อาจเปลี่ยนราคาได้ทุกเมื่อ

## ความเป็นส่วนตัว

- **API Key** อยู่ในหน่วยความจำเท่านั้น ไม่ถูกบันทึกลงเครื่อง ปิดแอปแล้วต้องวางใหม่
- **ไฟล์เสียง** ถูกส่งไปที่ OpenAI เพื่อถอดเสียงเท่านั้น ไม่ได้ส่งไปที่อื่น
- **ประวัติ** เก็บไว้ในเครื่องของคุณที่ `~/.vd_transcribe_history.jsonl` (Windows: `C:\Users\<ชื่อผู้ใช้>\.vd_transcribe_history.jsonl`) ลบไฟล์นี้ได้ถ้าต้องการล้างประวัติ

## สำหรับนักพัฒนา

ต้องมี Python 3.10 ขึ้นไป

```sh
pip install -r requirements.txt
python app.py              # เปิดแอป
python app.py --selftest   # ทดสอบ
```

สร้างตัวติดตั้งเอง:

- Windows: `.\build_windows.ps1` (ต้องมี [Inno Setup 6](https://jrsoftware.org/isinfo.php))
- macOS: `sh build_macos.sh`

ออกเวอร์ชันใหม่: แก้ `AppVer` ใน `installer.iss` แล้ว push tag เช่น `git tag v1.0.1 && git push origin v1.0.1` จากนั้น GitHub Actions จะสร้างตัวติดตั้งทั้ง 3 แบบและอัปขึ้นหน้า Releases ให้อัตโนมัติ
